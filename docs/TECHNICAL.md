# 자체 로더의 검증과 재현

요약 → 구현 → 재현·이어받기 순서입니다. 기준일: 2026-11-16. 배포 등급: **preview**.

## 요약과 증거 한계

Mods Menu 원본 DLL과 스크립트를 격리하고 C++ 로더·전투 스크립트를 새로 작성했습니다. 기존 모드는 호출 형식, 이벤트 이름, 필드 의미 분석에 사용했습니다. 원본 DLL을 수정·포장한 결과물이 아닙니다.

실제 게임에서 자체 로더로 시작하고 저장된 위치까지 로드했습니다. 완막·회피 값을 쓰고 다시 읽었으며 모의 공격 타이밍을 실제 SlomoWorldSubsystem에 연결해 시작·해제를 확인했습니다. 0.2 버전은 게임 기본 설정 메뉴에 전투 보조 탭을 추가합니다. 실제 적과의 빨강·파랑 전투 검증은 아직 미완료이며, 메뉴 동작·모의 엔진 시험과 구분합니다.

## 소스와 실패 시 동작

- `native/loader.cpp`: Windows System32의 HID(Human Interface Device, 사용자 입력 장치) 함수 47개를 전달합니다. 시스템 DLL은 복사·수정하지 않습니다. 정확한 게임 파일 해시와 메모리 크기·시각 정보·6개 호출의 원래 바이트를 검사합니다.
- `native/game-build.json`: 지원 빌드 메타데이터입니다. 게임 파일을 디스크에서 패치하거나 라이선스 판정을 변경하지 않습니다.
- `tools/generate_native.py`: 전달 스텁과 정확한 스크립트 허용 목록을 소스에서 생성합니다.
- `scripts/boot.js`: 원래 `MainStart`를 실행하고 리플렉션으로 판정값·공격 이벤트를 연결합니다. 로더에 컴파일된 스크립트와 정확히 일치하는 바이트만 허용하며 임의 모드 폴더 탐색은 하지 않습니다.
- 설정 메뉴 연결은 같은 파일에 있습니다. 게임의 `SettingPanel`에 동적 탭 하나를 등록하고, 기본 설정 행과 설명 위젯을 생성합니다. 게임의 UI 레이어가 일시정지·커서·뒤로가기를 담당합니다. 기본 설정 값은 변경하지 않으며, 그래픽 미적용 변경의 확인 절차도 게임에 맡깁니다.
- `settings/JidonPBZ.json`: 제한된 숫자·불리언 설정이며 `eval`은 없습니다.
- `dist/hid.dll`, `bundle.lock.json`: 자체 빌드 파일과 SHA-256(Secure Hash Algorithm 256-bit, 파일 동일성 검사값) 목록입니다. 해시는 동일성 확인이며 무해함의 증명이 아닙니다.

로더·전투 스크립트에는 네트워크, 레지스트리, 명령 실행, 자동 업데이트, 계정 접근 코드가 없습니다. 설치 도구의 프로세스 확인과 Git 동기화, 선택적 세이브 디코더는 게임 안에서 실행되지 않는 별도 작업입니다. 이 설명은 운영체제나 게임 전체의 무해함을 증명하지 않습니다.

지원 빌드가 아니거나 스크립트가 누락·변경되면 후킹하지 않습니다. 시스템 HID 전달은 유지합니다. 지정 스크립트의 바이트와 CommonJS 래퍼 전체만 예외로 허용하고 다른 스크립트는 게임의 원래 검증을 거칩니다. 시작 시 거부되면 원래 MainStart로 돌아갑니다.

호출 변위는 정렬된 8바이트 원자적 비교·교환으로 변경하고 시작 호출을 마지막에 연결합니다. 실패하면 되돌리기를 시도합니다. 재실행에서 상위 주소 공간이 비어 있지 않은 사례가 있어 하위 범위도 탐색하도록 보완했습니다. 메모리를 구하지 못하면 원래 게임으로 실행되며 실제로 타이틀 도달을 확인했습니다. 모든 동시 실행·메모리 장애를 증명한 것은 아닙니다.

전투 코드는 완막 두 필드와 완벽 회피 효과 객체를 변경하며 반복 적용으로 배수가 누적되지 않습니다. 완막 필드는 정수 프레임이어서 배율 적용 후 반올림하고, 회피는 초 단위 실수를 사용합니다. 자체 키 `JidonPBZ.Slow`만 지웁니다. 빨강·파랑만 반응하고 자동 방어는 없습니다. 특정 투사체나 해당 이벤트가 없는 공격은 미확인입니다.

## 검증 수준

현재 메뉴 버전의 파일 해시와 실기 검증은 [0.2 메뉴 검증 기록](validation-menu-2026-11-16.json)에 있습니다. [0.1 검증 기록](validation-2026-11-16.json)은 이전 배포본의 모의 슬로모션·스크립트 변조 거부 시험을 보존합니다. 일반 난이도 완막 기본값 8→16, 완벽 회피 0.15→0.30초를 읽었으며 기능을 끄면 각각 기본값으로 복구됐습니다.

| 시험 | 증거 수준 |
|---|---|
| 실제 시작·세이브 로드·판정값 읽기 | 게임 로그와 화면 |
| 기본 설정 탭·F9 열기·Esc 닫기·7항목 변경·즉시 저장·재시작 유지·음향 탭 왕복 | 실제 게임 화면과 JSON·판정값 로그 |
| 시간 제어 시작·해제 | 모의 공격 타이밍 + 실제 게임 시스템 |
| 배수 누적 방지·색상·완막 결과·사망·정지·플레이어 교체·설정·진단 실패·메뉴 저장 실패·반올림·단정도 오차 | Node.js 모의 엔진 시험 17개 |
| 설치·백업·복구·경로·무결성·부분 실패·이전 자체 배포본 식별 | Python 임시 폴더 시험 9개 + 실제 묶음 설치·설정 보존·내보내기·복구 통합 시험 1개 |
| 실제 적 공격·모든 보스·지역 이동 | 미완료 |
| 스크립트에 주석을 추가한 무결성 실패 | 후킹 거부 로그 + 원래 게임 타이틀 도달 |
| 다른 PC·다른 게임 버전 | 미완료 / 지원 해시 외 적용 거부 |

설치 도구는 자체 DLL과 스크립트 두 경로만 허용합니다. 게임 종료, 백업, 쓰기 직전 내용, 원자적 교체, 읽기 검증을 거칩니다. 실패 시 이번 내용과 일치하는 파일만 복구해 다른 변경을 보존합니다. 정전·디스크 장애까지 보장하지 않습니다.

게임 내 저장은 엔진의 파일 저장 기능으로 직전 설정을 `.previous`에 보관한 뒤 JSON을 쓰고 다시 읽습니다. 설치 도구의 원자적 교체와는 다르므로 쓰기 도중 정전까지 보장하지 않습니다. 원본 Mods Menu DLL·스크립트를 실행하거나 메뉴 코드를 배포본에 동봉하지 않습니다.

## 재현과 이어받기

Windows Visual Studio 2022 Community의 C++ 도구, Python, Node.js를 사용합니다. 다른 VS 설치 위치라면 `native/build.cmd`의 `vcvars64.bat` 경로를 조정하세요. 소스 줄바꿈은 LF이며 생성 파일은 Git에서 제외합니다.

```powershell
py -3.12 tools/generate_native.py
.\native\build.cmd
py -3.12 tools/package_bundle.py
node tests/combat.test.cjs
py -3.12 -m unittest discover -s tests -v
```

스크립트 변경 시 반드시 로더를 다시 빌드하고 묶음 해시를 다시 만드세요. `native/previous-bundles.json`에는 실제 배포한 자체 DLL·스크립트 쌍만 기록합니다. 설치는 이 두 파일이 모두 일치할 때만 이전 자체 버전을 백업·교체하고 개인 설정을 보존합니다. 알 수 없는 DLL은 덮어쓰지 않습니다.

`selfTest:true`는 플레이어 로드 후 모의 파랑·빨강 공격을 처리 함수에 전달합니다. `SLOW_START`, `SLOW_STOP key_removed=true`, `SELFTEST_PASS`를 확인한 뒤 `false`로 되돌립니다. 기본 배포 설정에서는 꺼져 있습니다. 이 시험은 엔진의 공격 이벤트 발생 자체를 검증하지 않습니다.

읽기 순서: README → `scripts/boot.js` → `native/loader.cpp` → `native/game-build.json` → `tools/mod_sync.py` → tests. Windows 구현은 [Microsoft DLL 모범 사례](https://learn.microsoft.com/en-us/windows/win32/dlls/dynamic-link-library-best-practices), CommonJS 실행 모델은 [Tencent Puerts](https://github.com/Tencent/puerts/blob/master/unreal/Puerts/Source/JsEnv/Private/JsEnvImpl.cpp)를 참고했습니다.

재개 요청: “PBZ-Mod-Sync의 README와 docs/TECHNICAL.md를 읽고 자체 로더만 사용해 검증을 이어가라. 원본 Mods Menu DLL은 복원하지 말 것. 실제 적 공격 검증은 미완료이며 모의 시험과 구분하라. 게임 업데이트 시 해시·호출 위치를 재분석하고 검사를 무력화하지 말 것. 변경 후 빌드·설치·게임 로그·비공개 GitHub 읽기를 확인하라.”
